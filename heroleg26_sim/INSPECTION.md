# MuJoCo 静态模型检查入口

当前检查对象为重新导出的 4.SLDASM。用于检查 heroleg26 的装配位置、关节零位、转轴方向和外观/碰撞几何。使用现有 MuJoCo 3.2.7 环境，不需要 Isaac Gym、ONNX 或训练显卡。

## 启动

从本机桌面终端运行：

```bash
source /home/mcsw/RL_infantry/.venv-mujoco/bin/activate
python -E /home/mcsw/RL_infantry/RM-wheelleg-rl/heroleg26_sim/tools/inspect_model.py
```

默认读取 `/home/mcsw/RL_infantry/RM-wheelleg-rl/heroleg26_sim/urdf/heroleg26_visual.urdf`。全分辨率碰撞 OBJ 仍然保留，初次编译需要等待数秒。窗口使用原生 MuJoCo 查看器，保留左右侧栏；若侧栏被隐藏，按 Tab 恢复。

这是静态运动学检查：基座固定在源模型初始姿态，程序直接设置关节角并调用 mj_forward；不调用 mj_step，不积分动力学，不加载策略，不施加电机驱动。因此模型悬空、不下落属于正常表现。此处“基座固定”是检查程序保持其位姿，并非修改 URDF 或增加实车固定约束。

## 按键

先点击 MuJoCo 窗口获得键盘焦点。

| 按键 | 功能 |
|---|---|
| 1 / 2 / 3 | 选择 LJ1 / LJ2 / LJ3，对应左髋 / 左膝 / 左轮 |
| 4 / 5 / 6 | 选择 RJ1 / RJ2 / RJ3，对应右髋 / 右膝 / 右轮 |
| 右方向键或 `=` | 当前关节角度增加 5° |
| 左方向键或 `-` | 当前关节角度减少 5° |
| 上 / 下方向键 | 当前关节角度增加 / 减少 1° |
| Z | 当前关节回到 URDF 零位 |
| 0 | 所有六个关节回到 URDF 零位 |
| J | 显示或隐藏关节轴及选中轴标记 |
| C | 切换外观几何 / 原始碰撞几何显示 |
| P | 在终端打印当前选中关节的角度、世界坐标轴方向和显示模式 |
| Esc | 退出 |

右侧 Joint 面板也可调整关节。鼠标采用原生 MuJoCo 相机操作；可拖动旋转观察，滚轮缩放。选中关节的标记附带关节名称和当前角度；红色箭头代表该关节的正轴，正角度遵循右手定则。其余关节轴使用查看器内置显示颜色。

本工具会持续恢复指定几何显示组，防止数字键选择关节时触发原生几何分组快捷键而隐藏模型。J/C 是本工具管理的显示状态，按键不修改模型资源。

## 建议的检查顺序

1. 零位观察整体装配、左右对应关系及轮子位置。
2. 按 1，再按一次右方向键，观察 LJ1 正转方向，再按 Z 回零。
3. 依次检查 2～6，每次只动一个关节。
4. 按 C 对比碰撞外形与外观的位置。
5. 记录与实物/CAD 不一致的地方，再决定后续模型修正。

当前 J1/J3 为 continuous；左右 J2 为 revolute，源限位均为 −0.41538836197465～+0.872664625997165 rad（约 −23.8°～+50°），工具会夹紧到该范围。限位按新导出保留，并不自动证明实物没有干涉。两侧 J1/J3 正轴约为车体 +Y，两侧 J2 正轴约为 −Y；旧模型的左右相反转轴规则不再沿用。检查工具仍以 URDF 全零位启动；训练默认站姿已确认为两侧 J1=−25°、J2=+20°，轮关节为 0°，详见 CALIBRATION.md。

## 资源和物理参数保护

工具只在内存中解析网格的绝对路径、给显示/碰撞元素设置唯一名称，并添加临时浮动根用于保留车体惯量、同时由程序保持基座姿态。不会回写 URDF、网格、质量、质心、惯量、关节定义或电机参数。灯光、关节轴标记和相机仅用于显示。正常退出会检查源 URDF 和所有引用网格的 SHA-256。
