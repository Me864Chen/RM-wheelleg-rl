# RM2026 运动地形原型

本场景针对轮腿运动与碰撞验证，依据《RoboMaster 2026 机甲大师超级对抗赛比赛规则手册 V2.2.0 (20260807)》第4章。尺寸按毫米转为米。它是**有来源标注的地形原型**，不是完整官方CAD，也不声称所有场地细节均已精确复刻。

## 启动与恢复

在项目 `mujoco` 目录、激活已有虚拟环境后：

```bash
# 新比赛地形
python -E python_tools/run_rm2026.py --device cpu

# 返回原来的场景（原文件没有被修改）
python -E python_tools/onnx_mj_chuanlian.py --device cpu

# 几何与碰撞验证；--rollout额外执行20秒已有策略的平地行驶
python -E python_tools/verify_rm2026_scene.py --rollout

# 修改JSON参数后重新生成场景
python -E python_tools/build_rm2026_scene.py
```

运动键为1/2线速度负/正、3/4角速度正/负、7停止、0切换第一/第三人称。默认GLFW窗口支持真实按下/松开事件：按住持续增加对应目标速度，松开对应轴归零；窗口失焦会停止指令。线速度累加速率0.5m/s²、角速度累加速率1rad/s²，分别限幅±2.8m/s和±6rad/s。相反方向同时按下时该轴归零。线速度实际指令仍经过原有平滑环节，目标为零不等于机器人物理速度瞬间为零。

GLFW窗口保留鼠标旋转/平移/缩放及0键相机切换，用顶部状态文字替代原生左右面板。需要原MuJoCo左右调试面板时可加`--keyboard-backend viewer`（旧的按一下持续运动模式）；`--keyboard-backend pynput`使用原生面板和全局长按监听，但在Wayland下可能收不到窗口事件。默认GLFW模式不依赖全局监听，也不会触发数字键的原生显示快捷键。

累加速率在控制脚本的`CMD_LIN_HOLD_ACCEL`和`CMD_YAW_HOLD_ACCEL`修改。控制回归测试：`python -E python_tools/test_hold_controls.py`。启动位置位于红方平地，机身朝向由JSON控制。

## 坐标与碰撞约定

- x沿28m长边，y沿15m短边；场地中心为(0,0)。
- 地面从中线向两侧降低：`floor_z=-abs(y)*tan(1.5deg)`。1.5deg是手册1-2deg范围内的名义值。
- 地形高度以当地倾斜地面为基准。轮廓长度以场地平面参数表示；图纸公差及倾斜基准差别需按实场/CAD进一步校准。
- 所有道路、坡面、围挡、隧道顶板都有真实接触几何。非凸轮廓分解为凸三棱柱；中线处另行分割，防止凸包填平沟壑或地面起拱。
- 隧道侧壁和顶板独立建模；650mm沟壑没有架空台面，底部仍是比赛地面，并非无底洞。
- 地面使用有限实体，没有穿过全场的无限平面。
- 静态环境contype=2、conaffinity=1；沿用机器人相反的碰撞掩码。priority=1确保接触参数来自场景配置。
- 使用5ms物理步长，与现有控制脚本假定一致，策略为100Hz；机器人质量、惯量、关节和ONNX权重不变。

## 明确保留的推定和简化

下列内容**不应当作为官方精确尺寸**：

1. 图4-5未完整约束所有顶点。主要区域的位置、中央高地转角、连接道路及部分入口布局按示意图估计，存在与实场不一致的可能。
2. 隧道采用700x260mm矩形净空包络；通道长度650mm、顶板厚40mm及部分结构厚度是模型参数，不能作为官方CAD数据。
3. 起伏板图4-37按70mm总包络、240mm跨两个凸起（名义节距120mm）解释；板底厚度35mm和余弦凸起轮廓是推定值。该剖面需CAD或实测确认，尚未声称精确还原。
4. 梯形高地的400mm区域分割、中央装配区内部结构、公路衔接和非驾驶设施只保留简化占地碰撞包络。能量机关、基地等没有实现比赛机关行为。
5. 摩擦系数1.0、扭转/滚动摩擦、接触刚度均为工程初值，规则手册不能提供真实PVC接触辨识结果。需要按实车轮胎和地胶标定。
6. 场地细节未按CAD逐毫米复刻，不包含完整纹理、装饰、地缝、风机和弹丸环境。

这些假设集中于 `rm2026_parameters.json` 和生成的 `rm2026_manifest.json`，可追溯、可修改，不与机器人资产混合。

## 验证范围

验证脚本对编译后的MuJoCo模型做射线剖面、沟壑留空、隧道净空/内宽、自由落体接触、小体通过/高体受阻的物理测试。`--rollout`直接运行现有ONNX控制器，验证平地站立和带速度指令行驶，检查跌倒与数值警告。

这不代表当前策略能通过全部坡道或完成飞跃。特别是260mm隧道净空可能小于当前整车高度；碰撞阻止过高机器人进入是正确行为，不能通过关闭碰撞来伪造通行。对于43deg坡、70mm包络起伏板和650mm沟壑，仍需专门的策略验证或重新训练。

## 回退

比赛场景独立于原`mjmodel.xml`；原场景XML仍保持基线9205406的内容。使用原启动命令即可恢复原场地，同时保留后续长按控制更新。已经存在的`baseline-fpv-v1`标签保留，可用于完整恢复场地修改前的代码。不要使用`git reset --hard`丢弃尚未保存的新场景或控制修改。
